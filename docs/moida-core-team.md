# 모이다 기본 팀

기본 직원은 계정마다 항상 제공한다. 기존 전문 직원 ID·고용 설정·보고서를 유지하며, 전문 직원 추가는 기존 저장 경로를 사용한다. 캐릭터가 수행할 수 있는 역할과 실행 도구는 별개다.

| 이름 | 역할 | 결과물 | 현재 작업 연결 |
|---|---|---|---|
| 모아 | 요청 정리·총괄 | 요청 범위, 담당자 연결, 결과 요약 | AI 비서 대화와 기존 업무 실행·검수 |
| 째깍 | 일정·업무 | 일정표, 충돌·준비·마감 목록 | 일정·행사 화면, 계정 Google 캘린더 조회 |
| 두리 | 자료 조사 | 자료 조사, 출처·비교표 | 계정 자료 검색·본문 조회, 전달 자료 |
| 글림 | 글쓰기 | 문서·보고서·메일·안내문 초안 | 계정 자료, AI 비서의 문서 생성 도구 |
| 담이 | 기록 | 전사 기반 요약, 회의록, 후속 목록 | 통화 기록의 기존 녹음 처리, 계정 자료 |
| 셈이 | 분석 | 데이터 비교, 계산 근거, 분석 보고 | 읽을 수 있는 표·파일 본문과 전달 자료 |
| 빛나 | 콘텐츠 | SNS 초안, 이미지 구성안, 영상 대본 | 계정 자료와 연결된 콘텐츠 도구; 제작되지 않은 파일을 완료로 표시하지 않음 |
| 이음 | 소통 | 문의·답변·연락·문자 초안 | CRM·문자 화면, 사용자 확인 후 기존 발송 흐름 |

업무 요청에 직원 이름이 있으면 명시한 기본/고용 직원에게 배정한다. 그렇지 않으면 업무 키워드로 관련 직원 최대 8명에게 배정하며, 매칭되지 않는 요청은 모아에게 정리하도록 전달한다. 자동 배정은 계정 설정 조회 완료 후 허용한다.

작업 서버의 직원 도구는 자료·컨텍스트 읽기와 역할별 캘린더 조회다. 실제 문서 생성·녹음 전사·문자 발송 등은 AI 비서/기존 화면의 도구 흐름을 통해 수행한다. 직원 작업 자체가 외부 게시·발송·예약을 실행하지 않는다. 항상 연결 상태와 실제 도구 결과를 기준으로 완료 여부를 판단한다.

캐릭터 이미지는 승인된 팀 시안을 바탕으로 생성한 투명 배경 4×2 아틀라스이며 CSS에서 각 프로필 영역을 표시한다. 직원 이름·역할은 이미지에 넣지 않고 HTML로 표시한다.
